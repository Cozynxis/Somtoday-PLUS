# Somtoday+

Een nieuwe browserextensie die Somtoday persoonlijker, slimmer en fijner maakt.

## V1 basis
- Eigen Somtoday+ instellingenvenster in Somtoday
- Categorieën voor Algemeen, Uiterlijk, Achtergrond, Startpagina, Rooster, Cijfers, Apps en Geavanceerd
- Accentkleur, ronde kaarten, animaties en compacte weergave
- Gradient achtergrond met twee instelbare kleuren
- Instellingen worden lokaal opgeslagen met `chrome.storage`
- Modulaire mapstructuur voor toekomstige features

## Installeren tijdens ontwikkeling
1. Download/clone deze repository.
2. Open `chrome://extensions`.
3. Zet **Ontwikkelaarsmodus** aan.
4. Kies **Uitgepakte extensie laden** en selecteer de repositorymap.
5. Open Somtoday. Rechtsonder verschijnt de knop **Somtoday+**.

Somtoday+ is een onafhankelijke extensie en is niet officieel verbonden aan Somtoday.
